# Store Local Source notes as canonical files

Authoritative Local Source notes will live as portable, title-named Markdown files in a dedicated backup-eligible app-private directory. People access copies through explicit Share, Portable Export, or KGS Archive rather than a live externally editable folder. Versioned human-readable records under `.kgs/` preserve stable IDs, favorites, automatic-title state, empty categories, Trash retention, and attachment ownership without polluting note content. Canonical file changes use crash-safe replacement, while metadata changes, attachment operations, and synchronization work use a durable, resumable operation journal. Room will be a rebuildable unified projection for search and app queries, while external working copies, credentials, and synchronization state live in physically separate backup-excluded storage; this file-level seam makes selective Android backup enforceable because platform rules cannot select individual rows from a mixed database.
