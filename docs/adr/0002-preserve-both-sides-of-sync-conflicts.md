# Preserve both sides of sync conflicts

KGS Notes will never resolve concurrent note edits with silent last-writer-wins behavior. A connector should use the source's revision token and a retained base snapshot to merge non-overlapping changes automatically; when a safe merge is impossible, the app presents base, local, and source content with a source diff, rendered preview, manual merge, and explicit local/source/keep-both outcomes. Every discarded side becomes a Revision. If an external source deletes a note that still has pending local edits, those edits become a Recovered Note in the Local Source and the original remains in Needs Attention for an explicit republish-or-discard decision. Before KGS itself deletes an external note, the connector fetches the latest state and diverts intervening changes into conflict handling before capturing Trash content and requesting deletion; this narrows, but cannot eliminate, races on sources without conditional delete.
