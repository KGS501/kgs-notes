# Retain meaningful local revisions

KGS Notes will keep user-visible local checkpoints for at least 30 days, capped at the latest 50 per note, independently of Trash and any source-provided history. Checkpoints occur before risky transformations or reconciliation and at meaningful editing boundaries rather than on every keystroke, providing bounded recovery from conflicts, link rewrites, category moves, and accidental edits without turning autosave into an unbounded version stream. Eligible checkpoints are removed only when a later cleanup succeeds. Restoring first checkpoints the current state, then makes the selected Revision an ordinary synchronizable edit; copying the Revision into a new note remains available. Revision bodies are excluded from Android cloud backup but included by default in KGS Archive with an option to omit them.
